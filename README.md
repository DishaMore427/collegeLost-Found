# 🎓 College Lost & Found System

A **PHP & MySQL based College Lost & Found System** designed to help students report, search, claim, and manage lost and found items on campus. 🔍📦

## ✨ Features

- 👨‍🎓 **Student Registration & Login**
- 🔐 **Secure Session-Based Access**
- 📝 **Report Lost & Found Items**
- 🔎 **Search & Filter Items**
- 📍 **College Location Selection**
- 🖼️ **Upload Item Photos**
- 🙋 **Claim Verification System**
- 👨‍💼 **Admin Panel**
- ✅ **Verify / Reject Claims**
- 🔄 **Mark Items as Returned**
- 🗑️ **Delete Items & Photos**
- 📊 **Student Dashboard**
- 🌙 **Modern Dark UI**

## 🛠️ Technologies Used

- 💻 **PHP**
- 🗄️ **MySQL**
- 🌐 **HTML5**
- 🎨 **CSS3**
- ⚡ **JavaScript**
- 🚀 **XAMPP**

## 🔐 User Roles

### 👨‍🎓 Student

Students can:

- Create an account
- Login using their roll number
- Report lost/found items
- Browse campus reports
- Submit claims
- Track their reports and claims

### 👨‍💼 Admin

Admin can:

- View all reported items
- Verify or reject claims
- Mark items as returned
- Delete items and uploaded photos
- Manage the Lost & Found system

## ⚙️ Installation

1. 📥 Download or clone this repository.
2. 📂 Place the project inside:
   `C:\xampp\htdocs\`
3. ▶️ Start **Apache** and **MySQL** from XAMPP.
4. 🌐 Open:
   `http://localhost/lost_found/`
5. 🗄️ The database and required tables are automatically created through `config.php`.
